# PC Repair 3D Studio — استوديو صيانة الحاسوب ثلاثي الأبعاد

منصة تدريب تفاعلية ثلاثية الأبعاد لتعليم **صيانة وتجميع الحاسوب** للطلاب، مبنية بتقنيات الويب الحديثة مع محرك 3D كامل يعمل داخل المتصفح.

> الهدف الأساسي: أن يتدرب الطالب فعلياً على تشخيص الأعطال وتركيب/فك القطع وتوصيل الكابلات وتشغيل الجهاز — داخل بيئة 3D واقعية — بدلاً من واجهات اختبارات نظرية.

---

## 🧰 التقنيات المستخدمة

| الطبقة | التقنية |
|---|---|
| الإطار الأساسي | **Next.js 16 (App Router)** + **TypeScript 5** |
| الواجهة | **Tailwind CSS 4** + **shadcn/ui** (New York) + **Lucide Icons** |
| المحرك ثلاثي الأبعاد | **Three.js** — GLB/glTF assets، Anchors، World-space Bounding Boxes |
| قاعدة البيانات | **Prisma ORM** + SQLite |
| إدارة الحالة | **Zustand** (client) + **TanStack Query** (server state) |
| وقت التشغيل | **Bun** |

---

## 🖥️ المزايا الحالية

- **مشهد 3D كامل**: غرفة صيانة تحتوي على جهاز حاسوب قابل للفك والتركيب قطعةً قطعة.
- **قطع حقيقية بأصول GLB عالية الدقة**: لوحة أم، معالج، رام، GPU، مزود قدرة، تخزين، مراوح…
- **شاشة تفاعلية داخل المشهد ثلاثي الأبعاد**: نظام تشغيل مرسوم على CanvasTexture يمكن التحكم به بالفأرة ولوحة المفاتيح الحقيقية (raycast → UV → pixel).
- **أدوات تشخيص الأعطال**: محرك أعطال (fault engine) يولّد سيناريوهات صيانة واقعية.
- **كتالوج قطع** معلوماتي لكل مكوّن داخل الجهاز.

## 📁 هيكل المشروع

```
src/
├── app/            # صفحات Next.js (App Router) + API routes
├── components/
│   ├── lab/        # مختبر 3D — المشهد، القطع، التفاعلات
│   ├── screens/    # الشاشة التفاعلية داخل المشهد
│   └── ui/         # مكونات shadcn/ui
├── lib/            # محرك الأعطال، كتالوج القطع، أدوات مساعدة
prisma/             # مخطط قاعدة البيانات (schema.prisma)
public/             # الأصول ثلاثية الأبعاد (GLB) والصور
```

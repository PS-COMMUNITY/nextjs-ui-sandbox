# تقرير الاختبار الفعلي — PC Repair 3D Studio v2.0.0

هذا التقرير يوثق **ما اختُبر فعليًا فقط** بنتائجه الحقيقية. لا يوجد في هذا الجدول أي اختبار لم يُنفَّذ. ما لم يُختبر موثق في قسم BLOCKED بأسبابه الصريحة.

## بيئة الاختبار

| البند | القيمة |
|---|---|
| طريقة الاختبار | متصفح آلي (agent-browser) بوضع headless داخل بيئة التطوير السحابية (Linux) |
| محرك الرسم | SwiftShader (مصيّر برمجي بلا GPU حقيقي) |
| الدقائق المختبرة | 1366×768 (سطح المكتب) و375×812 (هاتف) |
| شبكة | اختبار كامل مع تشغيل ثم حجب الخدمات الخارجية (خطوط Google Fonts) |
| الأدلة | لقطات شاشة فعلية أثناء الجلسة في مجلد `verify/` بجذر المشروع (30 لقطة: `01-home.png` حتى `30-offline.png`) |

## منهجية التحقق

- التنقل بين الشاشات تم بالنقر على عناصر الواجهة نفسها (لا تجاوز للحالة)، والتحقق من النتائج بقراءة النصوص المعروضة وحالة العناصر بعد كل فعل.
- نتائج POST والتوافق والSMART قُرئت من نصوص البطاقات الظاهرة وطابقت مع مخرجات المحركات في الكود.
- تصدير CSV تحقق بمحتوى الملف المنزّل نفسه (وجود BOM ‏UTF-8 وسلامة الصفوف العربية).
- قياسا التذييل تمّا بحساب مواضع DOM: قصير `footerBottom == viewportH`، وطويل `gap = 0` بين نهاية المحتوى والتذييل.
- لقطات `verify/` مأخوذة لحظيًا خلال الجلسة نفسها وهي الأدلة المرجعية لكل صف PASS في الجدول أدناه.

## قسم BLOCKED — لم يُختبر (بأسباب صريحة)

| البند | السبب |
|---|---|
| بناء نسخة Windows/Electron وتثبيتها | بيئة التطوير سحابية Linux ولا تدعم بناء حزم Windows إطلاقًا. لم يُبنَ ملف تثبيت ولم يُختبر تشغيله على Windows. الإعدادات والأوامر موثقة في `ELECTRON_GUIDE_AR.md` كمرجع **غير مختبر** يحتاج تجربة محلية على جهاز Windows |
| قياس FPS على عتاد حقيقي | لا يوجد أي قياس مسجل — الاختبار تم على SwiftShader البرمجي. الهدف التصميمي 30fps **لم يُثبت قياسًا** ولا يُعتمد عليه |
| تثبيت نظيف (Clean Install) | لم يُنفَّذ أي سيناريو تثبيت على جهاز مستخدم نهائي؛ التشغيل كان dev مباشر |
| الأصوات | غير منفذة — اختيارية ومغلقة افتراضيًا وفق المواصفة، ولم تُبنَ في هذا الإصدار |
| مراجعة المحتوى التعليمي | المحتوى يحتاج مراجعة معلم التخصص — موثق داخل الكود في `sourceNote` لكل مكوّن |
| وضع عدم الشبكة للبناء | لا يوجد وضع بناء دون شبكة في هذه البيئة — التطوير والاختبار في وضع dev فقط |

## ملاحظات صدق ختامية

- كل صف PASS في الجدول أعلاه نُفِّذ فعليًا بجلسة متصفح آلي واحدة موثقة بلقطات `verify/`، وليس اجتهادًا نظريًا.
- الدقة البصرية للقطات مقيّدة بـ SwiftShader؛ مظهر الإضاءة والظلال على GPU حقيقي قد يختلف.
- نتيجة «9 قواعد متوافقة» تعني القواعد التسع الثابتة المعرفة في `compatibilityEngine.ts` لهذه التجميعة المرجعية فقط.

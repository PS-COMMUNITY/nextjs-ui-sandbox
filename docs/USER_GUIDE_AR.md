# دليل المستخدم — PC Repair 3D Studio v2.0.0

دليل عملي بالعربية لكل شاشة وكل زر. التطبيق عربي كامل الاتجاه (RTL) ويُتنقل بين شاشاته من الشريط الجانبي.

## التحكم داخل المشهد ثلاثي الأبعاد (شاشة المختبر)

| الإجراء | النتيجة |
|---|---|
| النقر على قطعة | تحديدها (إبراز أخضر + بطاقة معلومات متزامنة) |
| السحب بالزر الأيسر | تدوير الكاميرا (Orbit) |
| عجلة الفأرة | تقريب / إبعاد |
| السحب بالزر الأيمن | تحريك الكاميرا (Pan) |
| نقر مزدوج | إعادة الكاميرا للموضع الافتراضي |

أزرار المختبر الرئيسية: **الأشعة السينية (X-Ray)** لجعل الهيكل شفافًا، **العرض التفجيري** لتباعد القطع، **إعادة الكاميرا**، **إخفاء الألواح الجانبية** لتوسيع المشهد، وقائمة اختيار الجودة. لوحة القائمة (Checklist) تعرض خطوات الفك/التركيب المتاحة الآن فقط — الخطوة غير المستوفاة لشروطها تظهر سبب رفضها بالعربية.

## 1) الشاشة الرئيسية

تعريف بالمشروع وأهدافه، وبطاقة «اختصارات التعلم» التي تنقلك مباشرة إلى: المختبر، الكتالوج، التدريب الموجه، الدروس. ابدأ من هنا ثم اضغط «المختبر 3D».

## 2) المختبر 3D — قلب التطبيق

1. عند الدخول يظهر الجهاز مطفأً ومغلقًا: كل الأعلام (powerOn، acConnected، panelOpen…) = false وكل القطع مثبتة.
2. لوحة «حالة الجهاز» تعرض الأعلام الـ13 كمفاتيح قابلة للقلب مع إرشاد لكل علم.
3. انقر قطعة (مثل بطاقة الرسوميات GPU) لتتحدد وتظهر بطاقة معلوماتها: الدور، الموضع، خطوات الفك المطلوبة.
4. لفك قطعة: اتبع لوحة القائمة بالترتيب — كل خطوة تُفتح عندما تستوفي شرطها السابق.
5. القطعة المفكوكة تتحرك حركة سلسة (lerp) إلى **صينية القطع** على الطاولة يسار الجهاز.
6. لإعادة التركيب نفّذ الخطوات العكسية (التثبيت ← إغلاق المزلاج/البراغي ← إغلاق الغطاء).

**سلسلة فك بطاقة الرسوميات كاملة:** إطفاء الجهاز ← فصل كابل الكهرباء من الحائط ← فتح الغطاء الجانبي ← فصل كابل طاقة البطاقة ← فك براغي البطاقة ← تحرير مزلاج PCIe ← إزالة البطاقة.

**رسائل الرفض التعليمية:** محاولة التشغيل بقطع ناقصة تعرض «أول قطعة ناقصة: …» (مثال فعلي اختُبر: «أول قطعة ناقصة: قرص M.2»)، ومحاولة توصيل كابل الطاقة والمزلاج محلَّر تُرفض برسالة «أغلق المزلاج قبل توصيل الكابل».

## 3) كتالوج القطع

12 مكوّنًا: case, motherboard, cpu, cooler, ram, gpu, psu, ssd, fans, atx24, eps, gpuPower. لكل مكوّن: الاسم عربي/إنجليزي، التصنيف، الدور، وصف تعليمي، مواصفات مرجعية، موضع التثبيت، خطوات الفك والتركيب، الأعطال المحتملة، تنبيهات السلامة، ملاحظات التوافق، وتقدير استهلاك طاقة معلن أنه توضيحي (`isIllustrative`).

## 4) التدريب الموجه

- اختر مهمة (مثل **«السلامة أولًا»**) واقرأ الهدف وتنبيهات السلامة.
- نفّذ الخطوات بالترتيب؛ كل خطوة تتحقق آليًا من حالة المحاكاة (علم مطلوب مفتوح/مغلق، أو قطعة مُزالة/مُركبة، أو نتيجة POST معينة).
- شريط التقدم يتحرك حيًا، وعند إتمام كل الخطوات يظهر توست إتمام وتُسجَّل المهمة في سجلك (اختُبرت مهمة «السلامة أولًا» وأكتملت تلقائيًا مع التوست).

## 5) التجميعة والتوافق

1. اختر قطعة لكل خانة (cpu, cooler, motherboard, ram, gpu, ssd, psu, case).
2. اضغط «فحص التوافق»: تُعرض **9 قواعد** ثابتة (socket-match, ram-type, board-case, gpu-length, cooler-fit, psu-capacity, gpu-power-connector, eps-present, m2-slot) بحالة متوافق/غير متوافق/يحتاج مراجعة مع سبب تفسيري.
3. القسم التقديري للطاقة يحسب استهلاكًا إجماليًا وقدرة PSU موصى بها **بهامش إرشادي 30%** مقرّبًا لأقرب 50 واط، مع تنبيهات صريحة أن الأرقام تعليمية.
4. اختُبر فعليًا: التجميعة المرجعية = 9 قواعد متوافقة، واختيار معالج AM5 مع لوحة LGA1700 يُكتشف برسالة تفسيرية.

## 6) التشخيص (POST وسيناريوهات الأعطال)

- **فحص POST** يعمل على الحالة الحالية ويعطي نتيجة واحدة حتمية: `POWER_OFF` (مطفأ/غير موصول)، `POST_FAIL` (معالج/ATX24/EPS/ذاكرة ناقصة)، `POST_PASS_BOOT_WARNING` (مثل مبرد أو قرص ناقص)، أو `POST_PASS_BOOT_OK`. POST منفصل عن الإقلاع: نتيجة «تحذير» قد تذكر صراحة No Boot Device عند غياب القرص.
- **سيناريوهات جاهزة** (6): قرص التخزين مفقود، بطاقة بلا كابل طاقة، EPS مفصول، RAM مفقودة، جهاز بارد، وسط مهمة إزالة اللوحة. طبّق سيناريو ثم اضغط فحص POST لترى الأثر.
- كل نتيجة تحمل تلميحًا ذكيًا للخطوة التالية وشارة أنها محاكاة تعليمية.

## 7) الطاقة والتخزين (SMART)

اختر سيناريو: **healthy** (99%، 38°م، 0 قطاع معاد تخصيصه، 4200 ساعة) أو **aging** (87%، 44°م، 12، 18000 ساعة) أو **failing** (41%، 52°م، 486، 31000 ساعة). تُعرض القيم مع تفسير تعليمي وشارة بارزة: **«محاكاة تعليمية — ليست قراءة من قرص حقيقي»**. القيم حتمية ثابتة لكل سيناريو ولا عشوائية فيها.

## 8) الدروس والاختبارات

اقرأ الدروس ثم افتح الاختبار (12 سؤالًا). أجب على الكل ثم أرسل: تظهر الدرجة، ومراجعة تفسيرية لكل سؤال (الصحيح ولماذا)، وتُحفظ نتيجتك في ملفك ويظهر متوسطك في التقارير.

## 9) التقارير

- إحصاءات الجلسة: عدد الأحداث، الأفعال الصحيحة/الفاشلة، عدد الاختبارات ومتوسط الدرجات، المهام المكتملة، آخر تشخيص.
- توصيات تعليمية مبنية على أدائك.
- جدول أحداث بزمن كل حدث ونوعه (safety/remove/install/post/quiz/…).
- **تصدير CSV**: نزّل الجدول فعليًا (UTF-8 مع BOM ليظهر العربي سليمًا في Excel)، وتصدير JSON للنسخ الاحتياطي.

## 10) الإعدادات

جودة الرسوميات (low/medium/high)، إعدادات الثيم، **نسخ احتياطي**: تصدير كل بياناتك JSON واستيرادها لاحقًا، ومنطقة الخطر: تصفير بيانات التدريب أو تصفير كل شيء. قسم «الاختصارات والمساعدة» يعيد عرض جدول التحكم بالمشهد أعلاه.

## مثال جولة كاملة (اختُبرت فعليًا)

1. من الرئيسية → «المختبر 3D».
2. شاشة التدريب الموجه → ابدأ **«السلامة أولًا»** → أطفئ الجهاز وافصل الكهرباء → تقدم حي حتى التوست الخاص بالإتمام.
3. في المختبر: حدد GPU → نفّذ سلسلة الفك السبع → تتحرك البطاقة إلى الصينية ويُحدَّث العدّاد (مثال فعلي: 10/12 قطعة مثبتة).
4. طبّق سيناريو «قرص التخزين مفقود» من التشخيص → وصّل الكهرباء وشغّل → فحص POST → النتيجة `POST_PASS_BOOT_WARNING` مع ذكر غياب وسيط الإقلاع (No Boot Device).
5. أعِد التركيب عكسيًا (تركيب البطاقة ← توصيل طاقتها ← إغلاق المزلاج ← البراغي ← الغطاء) ثم أعد الفحص لتصل إلى `POST_PASS_BOOT_OK`.
6. اختبار الدروس (12 سؤالًا) → التقارير → صدّر CSV.

## الأسئلة الشائعة

**س: هل أحتاج إنترنت؟** التشغيل لا يحتاجه (اختُبر التطبيق كاملًا مع حجب الخدمات الخارجية)؛ فقط خط Tajawal يُحمَّل من CDN عند توفره وإلا يُستخدم خط النظام.

**س: هل أتلف جهازًا حقيقيًا إن أخطأت؟** لا — كل شيء محاكاة داخل متصفحك، والرسائل تشرح الخطأ الصحيح تربويًا.

**س: أين تُحفظ بياناتي؟** في localStorage بمتصفحك فقط (مفتاح `pcrs_v1_state`)، مع تصدير JSON يدوي للاحتفاظ بنسخة.

**س: لماذا رُفضت خطوة فكّتها مبكرًا؟** لأن لكل قطعة اعتماديات (سلامة ← غطاء ← كابلات ← براغٍ ← مزلاج). اقرأ رسالة الرفض؛ هي تشرح أول شرط ناقص.

**س: أرقام الطاقة وSMART دقيقة؟** هي قيم تعليمية توضيحية معلنة (`isIllustrative`) وليست قياسات حقيقية.

# التحكم بالإدخال الحقيقي — INPUT_CONTROLS_AR (توجيه v3 §5)

**قاعدة أساسية:** لا يوجد لوحة مفاتيح ولا ماوس ثلاثي الأبعاد داخل المشهد إطلاقًا (v3 أ.1). ماوسك ولوحة مفاتيحك الحقيقيان هما أدوات التحكم بالتطبيق.

## الماوس الحقيقي (داخل نافذة المشهد)

| الفعل | النتيجة |
|---|---|
| **نقرة يسار على قطعة** | تحديد القطعة — تُبرز بلون تقني وتفتح بطاقة معلوماتها في اللوحة الجانبية (المعرف نفسه في المشهد والبطاقة) |
| **نقرة يسار على زر الشاشة/زر طاقتها في المشهد** | تشغيل/إطفاء الشاشة الافتراضية |
| **سحب الزر الأيسر على فراغ** | تدوير الكاميرا حول الجهاز (OrbitControls بتنعيم) |
| **عجلة الماوس** | تقريب/إبعاد (حدود 2.2–14 وحدة) |
| **سحب الزر الأيمن** | تحريك المشهد (Pan) |
| **دبل-كليك** | إعادة ضبط الكاميرا إلى المنظور الافتراضي |
| **سحب قطعة (في وضع السحب فقط)** | فك/تركيب مباشر — انظر أدناه |
| نقرة على فراغ | إلغاء التحديد |

- النقرة تُقبل فقط إذا كانت المسافة بين الضغط والرفع أقل من 6px — السحب لا يُعد نقرة.
- النقر على لوحات الواجهة المفتوحة لا يمس المجسم خلفها.

## وضع السحب (الفك/التركيب بالماوس)

يُفعّل من زر **«وضع السحب»** في شريط أدوات المشهد (توجيه v3 أ.2: السحب يعمل عند فعالٍ وضع الفك/التركيب):

1. **اسحب قطعة «فصل جزئي» نحو صينية القطع** → يُنفّذ الاستخراج (بعد التحقق من شروطه).
2. **اسحب قطعة من الصينية (أو ملتقطة) نحو الجهاز** → يُحاول التركيب؛ عند الرفض تعود القطعة لموضعها مع رسالة تشرح السبب.
3. أثناء السحب: تتعطل الكاميرا، والقطعة تتبع المؤشر على سطح أفقي.
4. **القاعدة:** الحركة البصرية وحدها لا تنجح — كل إفلات يمر عبر محرك المنطق (`assemblyEngine`) فحسب توجيه v3 §6.

أزرار القوائم (فصل جزئي/استخراج/تقاط/تركيب) تبقى بديلًا كاملًا للسحب — لا فرق في النتيجة أو التحقق.

## لوحة المفاتيح الحقيقية

| المفتاح | الوظيفة |
|---|---|
| `R` | إعادة ضبط منظور الكاميرا |
| `F` | تركيز الكاميرا على القطعة المحددة |
| `X` | تبديل الأشعة السينية (مخطط القطع — شفافية الهيكل) |
| `E` | تبديل العرض التفجيري |
| `H` | إظهار/إخفاء تلميح التحكم فوق المشهد |
| `1` / `2` / `3` | مناظير جاهزة: أمامي / جانبي / علوي |
| `Esc` | إلغاء التحديد والعزل |

### حماية الإدخال النصي (إلزامية وفق v3 أ.2/§5)

- أي اختصار **يُتجاهل تمامًا** عندما يكون التركيز داخل `input` / `textarea` / `select` / `contenteditable`، أو مع ضغط `Ctrl/⌘/Alt`.
- **حقل «دفتر النظام»** أسفل المشهد هو مدخل النص الحقيقي: الكتابة فيه تظهر فورًا على الشاشة الافتراضية ثلاثية الأبعاد داخل نظامها المبسط — الحقل يُفعّل فقط عندما يقبل النظام الكتابة (بعد إقلاع ناجح) ويعرض حالة سطر الأوامر نفسها.

## أزرار شريط أدوات المشهد (بديل حاسم للاختصارات — إمكانية وصول)

مناظير أمامي/جانبي/علوي • تكبير + / إبعاد − • إعادة الضبط • الغطاء (فتح/إغلاق) • أشعة • تفجيري • هواء • الشاشة • وضع السحب • توجيه للقطعة • ملء الشاشة • إخفاء اللوحة • إعادة تهيئة.

كل زر يعمل فعليًا — لا أزرار شكلية (v3 §8).

## ملاحظات

- المفاتيح مقياسٌة بـ `e.code` فتعمل مع أي تخطيط لغة (عربي/إنجليزي).
- زر `H` يتحكم بالتلميح نفسه المعروض أعلى يسار المشهد (مقبض RTL: أعلى البداية).
- في وضع ملء الشاشة تعمل الاختصارات ذاتها، و`Esc` يعود للوضع العادي أولًا (سلوك المتصفح المعياري).

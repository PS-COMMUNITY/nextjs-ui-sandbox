# تخطيط المشهد — SCENE_LAYOUT (مراجعة v3)

## نظام الإحداثيات والمقياس

- **الوحدة = 10سم تقريبًا.** المحاور:
  - `X ∈ [0, 2.1]` — `0` جهة الغطاء الزجاجي، `2.1` جدار اللوحة الأم.
  - `Y ∈ [0, 4.5]` — `0` أرضية المشهد/قاع الهيكل.
  - `Z ∈ [0, 4.6]` — `0` خلف الجهاز، `4.6` الواجهة الأمامية.
- **اللوحة الأم عمودية** على الجدار عند `x=1.85`، وجهها نحو `-X` (نحو المشاهد والزجاج).
- المصدر الوحيد للحقيقة: `src/lib/scene/layout.ts` (CASE/BOARD/MOUNTS/TRAY/EXPLODE_VECTORS/PERIPH/VIEW_PRESETS/COLORS).

## الكابلات

كل الكابلات `TubeGeometry` على منحنيات CatmullRom بنقاط بداية/نهاية صريحة تصل موصلاتها — لا كابلات طائرة (تُخفى مجموعة كابل إشارة الشاشة كليًا عند فصلها بدل أن تطفو).

## صينية القطع المفكوكة

- طاولة أمام-يسار الجهاز: `X ∈ [-4.4, -2.3]`، `Z ∈ [0.5, 4.3]`، سطح `y=0.9`.
- لكل مكوّن فتحة راحة `TRAY.slots` ودوران استلقاء `TRAY.rotations` (اللوحة والمقبس تستلقيان بحوافها).
- القطعة الملتقطة للتركيب (`awaiting`) تطفو فوق فتحتها ±4سم — إشارة بصرية.

## الكاميرا

- **الافتراضية:** `pos [-6.8, 4.9, 9.4]` → `target [0.7, 2.05, 2.6]` — زاوية ثلاثية أرباع تُظهر داخل الصندوق والشاشة معًا (v3 §2.2).
- **مناظير جاهزة (v3 2.1):** `VIEW_PRESETS` — أمامي `[1.05,2.8,11.8]`، جانبي `[-7.8,3.4,2.4]`، علوي `[1.2,11.8,4.9]` — أزرار + اختصارات 1/2/3.
- **الشاشة:** `MONITOR_CAMERA` — توجيه سريع نحو سطح العرض.
- حدود المدار: مسافة `2.2–14`، ميل أقصى `1.45 rad` (لا نزول تحت الأرضية)، تنعيم damping، وتنعيم انتقالات `easeInOut` خلال 0.3–0.7ث.

## قواعد الحركة

- الفك/التركيب: **التحقق المنطقي أولًا** (`assemblyEngine`) ثم تحديث الحالة ثم تحرك المجسم — الحركة البصرية وحدها لا تكفي (v3 §6).
- العرض التفجيري إزاحات موجهة `EXPLODE_VECTORS` ولا يفسد حالة الفك المنطقية.
- الغطاء الجانبي يفصلي دورانًا حول مفصلته الخلفية `-1.75 rad` ولا يمر عبر القطع.
